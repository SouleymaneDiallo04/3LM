# ADR 0002 — React 19 au lieu de React 18

- **Date** : 2026-07-08
- **Statut** : accepté (même logique que l'ADR 0001, validée le 08/07/2026)

## Contexte

Le cahier des charges (§5.2) spécifie « React 18 + TypeScript ». Le scaffold
Vite installe **React 19**, version stable courante en juillet 2026, supportée
par tout l'écosystème requis (react-router, TanStack Table/Query, Recharts,
React-Leaflet, shadcn/ui).

## Décision

Conserver **React 19**, la mention « React 18 » étant lue comme « la version
stable courante » (cf. ADR 0001 pour Laravel). Aucun impact fonctionnel.

## Conséquences

- `package.json` : `react ^19`, `react-dom ^19`.
- Les bibliothèques UI listées au CDC seront installées dans leurs versions
  compatibles React 19 au moment de leur introduction (phases 2-3).
